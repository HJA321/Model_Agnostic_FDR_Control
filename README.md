# Model-Agnostic FDR Control

Research code for Group Gaussian Mirror (GGM) and Permutation SHAP Gaussian
Mirror (PSGM), including synthetic simulations and neural comparison methods.

## Scope

This source snapshot includes linear GGM, sequential neural mirrors, synthetic
data generators, AFS, adaptive group lasso and a data-splitting mirror baseline.
No real-world datasets, saved results, notebooks or trained weights are included.
High-dimensional neural configurations use 700 features (15 relevant, 685 null)
and a lookback of 5. Low-dimensional settings use 300 features and lookback 5.

## Environment

Use Python 3.10. The pinned direct dependencies match a previously tested
environment; a clean installation and full-scale GPU runs remain to be verified.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Running from the repository root

The scripts have substantial default training budgets. Use a small configuration
to check an installation before launching full experiments.

```bash
python -m simulation_codes.simulation
python simulation_codes/linear_extra_experiments.py --help
python simulation_codes/nn_four_baselines_driver.py --help
python simulation_codes/run_gj_lr_optimization_curves.py --help
```

The neural baseline driver runs AFS, AGL, the data-splitting mirror baseline and
fitted derivatives. PSGM itself is run by `simulation_codes/simulation.py`.

For example, to configure a high-dimensional GRU PSGM experiment:

```python
from simulation_codes import simulation as sim
sim.MODEL_TYPE = "gru"
sim.N_RELEVANT = 15
sim.N_IRRELEVANT = 685
sim.LOOKBACK = 5
sim.GROUP_KW_PCA_COMPONENTS = 2 * sim.LOOKBACK
sim.IMPORTANCE_MODES = ("shap",)
sim.main()
```

For a matching high-dimensional baseline configuration:

```bash
python simulation_codes/nn_four_baselines_driver.py --model-type gru --dimension-name highdim --n-relevant 15 --n-irrelevant 685 --lookback 5 --num-simulations 50
```

`simulation_codes/linear_extra_experiments.py` uses column counts, not group
counts: with group size 5, use 150 relevant columns and 1350/3350 null columns
for 300/700 groups respectively. Use `--data-mode lag_group` for the AR grouped
design, `--data-mode iid_group` for the static grouped design, and
`--experiment ar_error` for AR response errors and OLS/GLS comparisons.

## Reproducibility status

This is an executable research snapshot, not yet a validated reproduction of
all paper tables. Small CPU runs of the core methods and baseline paths passed.
Full-scale repetitions, clean installs and CUDA execution remain to be checked.
In particular, the following implementation choices still need reconciliation:

- Neural and simulation GGM thresholds have a nearest-ratio fallback when no
  threshold satisfies the requested FDR ratio; the standalone GroupGM library
  defaults to selecting nothing. The fallback does not enforce that inequality.
- Linear dimension routing, signal generation, and correlation settings require
  alignment with the final experimental specification.
- SHAP smoothing mode, permutation count and repetition budgets must be fixed
  explicitly; current defaults are not a complete paper reproduction recipe.
- The simulation group-lasso baseline uses the known support size in its
  regularization-path selection policy.

The root `simulation.py` is temporarily retained because the optimization-curve
script imports it. The baseline driver explicitly loads the subdirectory version.
Keep both until their import paths are consolidated. No existing experimental
results are included or claimed to have been regenerated by this export.
